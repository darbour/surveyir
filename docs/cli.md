# Command line

The `surveyir` command covers the common tasks. Run it with `uv run surveyir`
from a checkout. The outputs below are generated by running each command
(`scripts/update_docs.py`).

## `formats`: what can be read and written

```console
$ surveyir formats
Input formats:
  qualtrics    .qsf
Output formats:
  json         The surveyir IR as JSON (lossless unless compact=True).
  markdown     Readable Markdown of the flow and every question (good LLM context).
  codebook     CSV codebook: every response column with labels (Qualtrics naming).
```

Exporters registered by other packages (see [Exporting](guide/exporting.md))
appear here too.

## `inspect`: summary and load problems

```console
$ surveyir inspect tests/fixtures/qualtrics/accuracy_nudges.qsf
tests/fixtures/qualtrics/accuracy_nudges.qsf: 'Accuracy Nudge Pennycook et al. 2021 Study 5_Replication'
  95 questions, 34 blocks (0 not in flow)
  kinds: descriptive=31, choice=28, timing=25, slider=8, meta_info=1, matrix=1, text_entry=1
  flow:  block=35, branch=9, embedded_data=7, randomizer=7, end_survey=1
```

Info-level diagnostics are hidden unless you pass `-v`. `--json` gives
machine-readable output. `--extras` lists the source keys that have no typed
field yet:

```console
$ surveyir inspect tests/fixtures/qualtrics/hiring_algorithms.qsf --extras | head -n 12
```

`inspect` exits with status 1 if any file has warnings or errors, so it can
gate CI.

## `convert`: export to another format

```console
$ surveyir convert tests/fixtures/qualtrics/hiring_algorithms.qsf -t markdown | head -n 24
# Hiring algorithms Digital Twins

_26 questions in 6 blocks · source: qualtrics.qsf_

## Flow

- Set embedded data: `PROLIFIC_PID` (recipient), `STUDY_ID` (recipient), `SESSION_ID` (recipient)
- Block: **Consent**
- If Q31: “Disagree” is selected:
  - End survey (redirect)
- Block: **Block 1**
- Block: **Default Question Block**
- Block: **Block 2**
- Randomize: show 1 of 2 in random order, evenly presented
  - Block: **Algorithmic Hiring**
  - Block: **Hiring Team**
- End survey (redirect)

## Experimental design

    FL_7: between-subjects, 1 of 2, evenly presented
      - Algorithmic Hiring (p=0.5)
      - Hiring Team (p=0.5)

```

Write to a file with `-o`. Pass exporter options with `--opt key=value`; values
are parsed as JSON when possible:

```bash
surveyir convert study.qsf -t json --opt compact=true --opt indent=null -o study.json
surveyir convert study.qsf -t codebook -o codebook.csv
surveyir convert study.qsf -t markdown --opt language='"ES"' -o study_es.md
```

`--strict` fails instead of loading a survey with unsupported content.

`--json` writes the full design (factors, arms, assignments, order randomization,
random values, and anything not reproducible).

## `schema`: the JSON Schema

```console
$ surveyir schema | head -n 6
{
  "$defs": {
    "And": {
      "additionalProperties": false,
      "properties": {
        "type": {
```

`surveyir schema -o schema/surveyir.schema.json` regenerates the published
schema. CI checks that it is up to date.
